User Frontend Pages
AI Use Cases Tracker /ai-stats or /

Interactive real-time table tracking team usage of AI tools with concurrency-safe increment and decrement buttons (+1 / -1).

Visit →
What it contains:
  • Headers: Ai UseCase, Usege Count, and Action buttons (+ / −).
  • Tracked Rows:
    • Deployment requests raised using kiro
    • Bugs analyuzed using bug analyzer
    • Orders raised using order creation tool
    • Java upgrade agent use cases
    • AI-SDLC use cases
  • Persistence: Synchronized to GitHub Gist under ai-stats.json.
  • Safety: Mutex-queued updates prevent race conditions and lost counts.
Weekly Hours Tracker /hours

Timesheet logging and compliance verification page for cross-checking hours entered in Jett vs Fieldglass.

Visit →
What it contains:
  • Title Banner: Displays current week with computed start date and end date (e.g. Current Week: Oct 12 – Oct 18).
  • Submission Form: Member Name input + Box 1 (Hours in Jett) + Box 2 (Hours in Fieldglass).
  • Live Team Table: Compares Jett vs Fieldglass per person, highlights Match vs Discrepancy diffs, and computes team totals.
  • Persistence: Synchronized to GitHub Gist under weekly-hours.json.
Backend REST API Endpoints
GET /api/stats
Returns latest AI use case counts & Gist connection status
POST /api/stats/update
Safely increments (+1) or decrements (-1) counts via mutex
GET /api/hours
Returns current week range and member submitted hours
POST /api/hours
Adds/updates member's Jett & Fieldglass hours in Gist
POST /api/create-gist
1-click creation of a new GitHub Gist with both JSON files
